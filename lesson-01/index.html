1.1 什么是可视化网站？

可视化网站不是单纯展示文字的网页，而是把数据、视觉编码和用户交互结合起来，让用户能够通过图形快速理解数据。

1.2 一个网站由什么组成？

可以把制作过程理解为四层：先用 HTML 搭骨架，再用 CSS 做设计，用 JavaScript 添加行为，最后使用 D3.js 把数据转成图形。

  1. HTML：标题、文本、按钮、容器等。
  2. CSS：颜色、字体、间距、布局、响应式效果。
  3. JavaScript：点击、筛选、动态更新等。
  4. D3.js：数据与 SVG/DOM 元素之间的绑定和可视化。

网页最基本的结构由 html、head 和 body 组成。我们先做一个最简单的网页。

<!DOCTYPE html>
<html>
<head>
  <title>我的第一个网站</title>
</head>
<body>
  <h1>我的可视化网站</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>

在下面输入标题：

我的第一个可视化网站

这是一个简单的网页预览。
