4.1 JavaScript 做什么？

如果 HTML 是骨架、CSS 是外观，那么 JavaScript 就是让网页“动起来”的部分。可视化网站中的筛选、按钮、提示框、动态更新都离不开 JavaScript。

4.2 DOM 与事件

JavaScript 可以通过 querySelector 找到元素，再通过 addEventListener 监听点击、输入等事件。

下面的代码让一个数字随着用户点击按钮而变化。

let count = 0;

button.addEventListener("click", () => {
  count += 1;
  output.textContent = count;
});
