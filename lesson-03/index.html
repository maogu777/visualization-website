3.1 CSS 是什么？

CSS 负责“页面长什么样”。一个好的可视化网站需要清晰的层次、合理的留白和统一的视觉风格。

3.2 页面布局

Flexbox 适合一维排列，Grid 适合二维布局。课程首页的章节卡片就可以使用 Grid，让多个卡片自动排列。

CSS 的核心是“选择元素，然后修改它的属性”。

.card {
  background: white;
  border-radius: 16px;
  padding: 24px;
  border: 1px solid #e5e7ef;
}

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
