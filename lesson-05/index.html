5.1 D3.js 是什么？

D3.js 是一个基于 Web 标准的数据可视化库。它擅长把数据映射为网页中的 SVG、HTML 元素，并支持动画和交互。

5.2 数据与 SVG

柱状图可以理解为：每一个数据对象对应一个矩形。数据值越大，矩形的高度越高。

本例使用 D3 的比例尺把 0～100 的数据映射到 SVG 高度。

const y = d3.scaleLinear()
  .domain([0, 100])
  .range([height - margin.bottom, margin.top]);

svg.selectAll("rect")
  .data(data)
  .join("rect")
  .attr("x", d => x(d.name))
  .attr("y", d => y(d.value))
  .attr("height", d => y(0) - y(d.value));

鼠标移动到柱子上，可以看到交互效果。
