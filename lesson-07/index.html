7.1 综合项目

一个完整的可视化网站通常包含首页、章节或内容页面、数据文件、样式文件和 JavaScript 文件。开发时可以先完成静态页面，再逐步加入交互和可视化。

7.2 制作与部署流程

  1. 规划页面和数据。
  2. 用 HTML 搭建结构。
  3. 用 CSS 完成视觉设计。
  4. 用 JavaScript 添加交互。
  5. 用 D3.js 绘制图表。
  6. 本地测试后上传到 GitHub。
  7. 通过 GitHub Pages 发布静态网站。
