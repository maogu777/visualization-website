6.1 数据是什么？

可视化的基础是数据。网页可以读取 CSV、JSON 等结构化数据，也可以从接口获得实时数据。拿到数据后，需要先理解字段和数据类型。

6.2 数据处理流程

  1. 读取数据。
  2. 检查字段和类型。
  3. 根据需求筛选、排序或聚合。
  4. 把处理后的结果交给图表。
  5. 用户改变条件后重新计算并更新视图。

下面用下拉框模拟数据筛选：选择城市后，只显示对应数据。

const rows = data.filter(d => d.name === selected);

result.innerHTML = rows
  .map(d => `<p>${d.name}：${d.value}</p>`)
  .join("");
